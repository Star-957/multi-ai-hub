如何使用自己的模型？
  1. 從 GitHub 下載並安裝專案。
  2. 將 .env.example 複製為 .env，只在自己的電腦填入設定。
  3. 執行 pnpm start，開啟終端顯示的本機網址。

本機模型需要另行啟動 Ollama 並下載模型。雲端 API 可能產生費用。
